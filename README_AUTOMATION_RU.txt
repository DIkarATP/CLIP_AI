CLIP AI v1.3 — Twitch Live Monitor + Recorder (локальная тестовая сборка)

ЧТО УМЕЕТ ЭТА ВЕРСИЯ
- Сохраняет источники на локальном сервере в data/sources.json.
- Мониторит Twitch LIVE для включённых и подтверждённых источников.
- При обнаружении LIVE запускает Streamlink и сохраняет эфир в recordings/*.ts.
- Показывает состояние worker, активные записи и последние события в панели Clip Hunter.
- Мониторинг идёт каждые 30 секунд, пока запущен сервер и включён worker.

ВАЖНО О ПРАВАХ
Включай подтверждение только для собственных каналов или контента, на запись и переработку которого у тебя есть разрешение. Не записывай чужие трансляции без разрешения. Twitch API сам по себе не даёт права скачивать/перепубликовывать контент.

УСТАНОВКА ОБНОВЛЕНИЯ
1. Останови старый сервер: в чёрном окне Ctrl+C.
2. Сделай копию существующего файла .env в безопасное место. Не отправляй его никому.
3. Распакуй архив поверх папки clipai_twitch_connector, заменив server.py, index.html, start.bat и добавив requirements.txt/setup.bat/README_AUTOMATION_RU.txt.
4. Не удаляй и не заменяй .env.
5. Один раз запусти setup.bat и дождись установки Streamlink и yt-dlp.
6. После завершения запусти start.bat.
7. Открой http://127.0.0.1:8765/ и перейди в Clip Hunter.
8. В «Мои источники» поставь галочку подтверждения прав для своего/разрешённого канала, затем «Мониторить автоматически».
9. Мониторинг стартует автоматически при запуске start.bat; кнопкой в панели его можно остановить или запустить снова.

ЗАПИСИ
Файлы появятся в папке clipai_twitch_connector/recordings. Для записи нужен работающий компьютер, интернет и запущенный сервер. Если Streamlink не может получить поток (ограничения канала/платформы/географии/доступа), событие появится в журнале.

ОГРАНИЧЕНИЯ ЭТОЙ ВЕРСИИ
- Пока работает мониторинг и запись Twitch LIVE, не полноценная AI-нарезка.
- Автоматическая загрузка Twitch VOD, анализ речи/сцен, создание клипов, Telegram и публикация ещё не подключены.
- YouTube и Kick пока только сохраняются как источники, worker их не записывает.
- Для следующих этапов будут добавлены VOD worker, FFmpeg и AI-анализатор.
